# User guide (English)

## What this is

hyper-grid is a local desktop app for **perpetual grid trading** on Hyperliquid. You fund your account on the official site, paste your private key into the app, set a price range, and let it place orders.

## Install

Download from **GitHub Releases** (Windows / macOS / Linux). Prefer the official Release builds — they are packaged by CI for better compatibility.

## First run

1. Open the app  
2. Choose language in Settings  
3. Start with **Simulation**  
4. Configure symbol, price range, grid count, size → Preview → Start  
5. For live trading: Testnet or Mainnet, paste private key, refresh balances, then Start  

## Safety

- High leverage is risky  
- Never share your private key  
- Stop cancels orders and closes positions
