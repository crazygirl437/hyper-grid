# 用户指南（中文）

## 这是什么

hyper-grid 是本地运行的 Hyperliquid **永续合约网格**桌面软件。你在官网自行充值，把私钥填进软件，设好价格区间后由程序自动挂单。

## 安装

从 **GitHub Releases** 下载**便携版**（无需安装包）：

- Windows：`.exe` 双击运行
- macOS：`.app.tar.gz`（苹果芯片或 Intel 选对应文件，解压后打开）
- Linux：`.AppImage`（`chmod +x` 后运行；需 Ubuntu 22.04+）

## 第一次使用

1. 打开软件  
2. 在设置里选择语言  
3. 建议先用 **模拟盘**  
4. 配置交易对、价格上下沿、格数、投入 → 预览 → 启动  
5. 实盘：选测试网/主网，填私钥，刷新余额后再启动  

## 安全

- 高杠杆风险大  
- 私钥不要外传  
- 停止时会撤单并平仓
